# B7.4 Project Factory CLI Execution Plan

## Mission
Expose the existing Factory core through a minimal standalone CLI with `plan` and `generate` commands, relying purely on the deterministic domain boundaries with no Laravel HTTP/console boot.

## Milestones
- [x] C1 CLI entrypoint (`bin/factory`)
- [x] C2 Input schema/parser (`JsonProjectDefinitionParser`)
- [x] C3 Manifest catalog composition (Manual object graph construction)
- [x] C4 `plan` command (Invokes planner, text/json output)
- [x] C5 `generate` command (Invokes materializer with explicit destination)
- [x] C6 Deterministic output formatting (`PlanRenderer`)
- [x] C7 Safe destination handling (Argv parsing and mapping to `ProjectDestination`)
- [x] C8 Exit-code/error mapping (Stable return codes, stderr segregation)
- [x] C9 CLI tests (Isolated command execution)
- [x] C10 End-to-end disposable generation (Proving CWD independence)
- [x] C11 Full quality gates (Deptrac, PHPStan, PHPUnit)
