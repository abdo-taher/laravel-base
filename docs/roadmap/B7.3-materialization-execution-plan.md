# B7.3 Materialization Execution Plan

## Mission
Implement a safe filesystem materialization engine that executes a `GenerationPlan` inside a staging workspace and atomically publishes the final project.

- [x] M1 Materializer contracts (`ProjectMaterializer`, `FactoryExecutionResult`)
- [x] M2 Execution request/destination model (`ProjectDestination`)
- [x] M3 Staging workspace (Atomic naming, sibling to destination)
- [x] M4 Typed operation execution (CreateDir, CopyTree, CopyTemplate)
- [x] M5 Template substitution (Literal string replacements)
- [x] M6 Copy-tree safety (Symlink rejection, conflict detection)
- [x] M7 Atomic publish (`rename()`)
- [x] M8 Failure cleanup (Recursive delete of staging on error)
- [x] M9 Deterministic materialization tests (Identical byte-for-byte output)
- [x] M10 Disposable-project integration test (ReferenceCatalog end-to-end)
