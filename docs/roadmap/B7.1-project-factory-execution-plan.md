# B7.1 Project Factory Execution Plan

## Mission
Establish the architectural bounds, plans, and validation for the Project Factory without writing production execution code. Ensure the blueprint respects Foundation capabilities and existing Manifest dependency structures.

## Milestones
- [x] **M1 - Repository Inspection:** Analyze frozen B6 capability catalogs and resolver implementations.
- [x] **M2 - Boundary Definition:** Classify Factory as an independent Tooling layer mapping strictly to Foundation contracts.
- [x] **M3 - Domain Modeling:** Define conceptual models for `ProjectDefinition` and `GenerationPlan`.
- [x] **M4 - Resolution Strategy:** Validate that `ManifestDependencyResolver` is capable of handling aggregate target requests without reinvention.
- [x] **M5 - Safety & Idempotency Rules:** Draft the atomic staging workspace approach to prevent corrupted outputs.
- [x] **M6 - Architecture Enforcement (Deptrac):** Define `Tooling` bounds to prevent backwards-coupling into Base logic.
- [x] **M7 - Next Roadmap Sequences:** Draft the minimal path to execution for B7.2+.

## Implementation Roadmap (Post-B7.1)
- **B7.2:** Core Value Objects (`ProjectDefinition`, `GenerationPlan`) & Planner implementation (Dry Run).
- **B7.3:** Materialization Engine (Staging, File Copy, Template Swap, Atomic Commit).
- **B7.4:** Independent CLI binary.
- **B7.5:** Disposable-project E2E Acceptance Proof.
