## Contracts and Definitions

- `ExtensionContract` — framework-free root marker for registered extensions.
- `ContributorContract`, `DecoratorContract`, `StrategyContract`, and `MetadataExtensionContract` — explicit extension kinds.
- `ExtensionRegistry` — Public registration and lookup boundary.
- `ExtensionMetadataContract` — scanner-independent declarative metadata shape.
- `ExtensionMetadata` — PHP attribute implementing only that metadata contract; no reflection scanner.
- `ExtensionPoint` — readonly point name, kind, accepted contract, and collection policy.
- `ContributionDefinition` — readonly contribution ID, target point, implementation, priority, and metadata.
- `ExtensionDefinition` — readonly extension ID, enabled state, contributions, and metadata.

## Registration

- Extension points are registered explicitly; there is no hard-coded list.
- Extension registration validates every contribution before mutating registry state.
- Disabled extensions are rejected and contribute nothing.
- Contributions must target an existing point and implement both its accepted contract and declared kind.
- Duplicate extension IDs and duplicate point/contribution IDs fail closed.

## Resolution

- Extension points resolve by exact name.
- Contributors, decorators, strategies, and metadata extensions are collected separately.
- Collections are deterministic: higher priority first, then extension ID and contribution ID lexicographically.
- Unknown points fail lookup.
- No decorator chain execution or strategy engine is implemented.

## Tests

### Positive

- Register an enabled extension.
- Resolve a registered extension point.
- Collect contributors deterministically.
- Register and collect decorator, strategy, and metadata extension kinds.
- Attribute metadata exposes its declaration without scanning.

### Negative

- Duplicate incompatible contribution.
- Contribution that violates the extension point contract.
- Disabled extension registration.
- Unknown extension point and duplicate extension ID.

### Immutability

- ExtensionDefinition, ExtensionPoint, ContributionDefinition, and ExtensionMetadata are readonly.
