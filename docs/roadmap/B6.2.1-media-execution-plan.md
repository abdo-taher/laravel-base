# B6.2.1 Platform.Media Execution Plan

## 1. Implementation Milestones
1.  **Public API**: Define Contracts, Value Objects, and Exceptions.
2.  **Manifest & Service Provider**: Define `module.json` and `MediaServiceProvider`.
3.  **Persistence**: Create the `media` table migration and an internal Repository using Eloquent.
4.  **Application Logic**: Implement `MediaUploader`, `MediaSynchronizer`, and `MediaCleaner`.
5.  **Infrastructure/Files Integration**: Bind Application interfaces to `Platform.Files` dependencies and internal DB models.
6.  **Deptrac & Validations**: Update `deptrac.php`, write Architecture/Unit/Integration tests, run quality gates.

## 2. Files Expected to be Created/Modified
- `packages/base/Platform/Media/module.json`
- `packages/base/Platform/Media/MediaServiceProvider.php`
- `packages/base/Platform/Media/Public/ValueObjects/*`
- `packages/base/Platform/Media/Public/Contracts/*`
- `packages/base/Platform/Media/Public/Exceptions/*`

- `packages/base/Platform/Media/Infrastructure/Repositories/*`
- `deptrac.php`
- `tests/Unit/Packages/Base/Platform/Media/*`

## 3. Dependency Changes
- Media requires `Platform.Files`.
- Media has NO dependency on Identity or Settings.
- Deptrac rules will enforce this strictly.

## 4. Persistence Work
- Create a single `media` table migration mapping exactly to the single-owner MVP polymorphic schema defined in the architecture plan.

## 5. Public API Work
- Value Objects: `MediaReference`, `MediaAccessScope`, `MediaOwnerReference`, `MediaSlotName`, `MediaSlotDefinition`, `MediaSlotChange`, `MediaSlotChanges`.
- Contracts: `MediaUploader`, `MediaSynchronizer`, `MediaCleaner`.
- Exceptions: `InvalidMediaReference`, `MediaSlotViolation`, `MediaUploadFailed`.

## 6. Validation Gates
- PHPStan analysis.
- Deptrac coverage.
- PHPUnit testing covering single/multiple slots, order retention, attach-once, access-scope enforcement, and rollback integrity.
