# B7.5 Runnable Project Acceptance Plan

## Host Skeleton Architecture
**Decision:** We will create a canonical trusted skeleton in `templates/project-host/` containing ONLY the minimal files needed to boot Laravel 11/12 (artisan, app/, bootstrap/, config/, public/, routes/, storage/, resources/, composer.json). We will NOT blindly copy the entire `base-next` repository.
**Mandatory Baseline:** There is NO mandatory `packages/base/Foundation` baseline. The generated project is a standard Laravel app. Packages are resolved purely through the capability graph. `Foundation` is only included if a module depends on it.

## Execution Plan
- [ ] H1 Create `templates/project-host/` and copy minimal Laravel skeleton from root.
- [ ] H2 Exclude `Tooling/ProjectFactory` from the skeleton.
- [ ] H3 Modify the `composer.json` template in `templates/project-host/composer.json` to properly autoload `Base\`, `Modules\`, and `App\`.
- [ ] H4 Extend `ProjectMaterializer` to first materialize the `project-host` skeleton into staging, then run the plan operations.
- [ ] H5 Generate `bootstrap/providers.php` dynamically based on the resolved `GenerationPlan` to automatically boot the `ServiceProvider`s for all resolved packages and modules.
- [ ] H6 Add E2E Acceptance Test generating the project, running `composer install`, `php artisan migrate`, and verifying `/api/media` and `/api/reference-items` are reachable and usable.
- [ ] H7 Final quality gates (phpstan, pint, test suite).
