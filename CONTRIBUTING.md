# Contributing

## Before Coding

1. Read AGENTS.md.
2. Read BUILD_PLAN.md.
3. Record the implementation plan.
4. Identify affected modules and public contracts.
5. Identify required tests.

## Change Scope

Prefer the smallest coherent vertical slice.

Avoid unrelated refactoring.

## Definition of Done

A change is complete only when:

- applicable tests pass
- architecture rules pass
- static analysis passes when configured
- security checks pass when configured
- documentation is updated
- BUILD_PLAN.md accurately reflects progress

## Commits

Use focused commits with descriptive messages.

Do not mix architecture changes with unrelated cleanup.
